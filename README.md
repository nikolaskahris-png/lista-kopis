# Λίστα Κοπής

Εφαρμογή για κινητό, για τη λίστα κοπής σε ντουλάπια κουζίνας, ντουλάπες ρούχων και μπάνιο.

- Δουλεύει **χωρίς ίντερνετ** (μπαίνει ως εικονίδιο στην αρχική οθόνη του κινητού).
- **Κανένα AI, καμία σύνδεση σε εξωτερική υπηρεσία.** Όλοι οι υπολογισμοί γίνονται με τους σταθερούς τύπους του `kanones-kopis.md` μέσα στη σελίδα. Ίδια μέτρα μέσα = πάντα ίδια λίστα έξω.
- Τα στοιχεία των δουλειών μένουν **μόνο μέσα στο κινητό** (δεν ανεβαίνουν πουθενά).

## Αρχεία

| Αρχείο | Τι κάνει |
| --- | --- |
| `index.html` | Όλη η εφαρμογή (οθόνες, σχέδιο, ρυθμίσεις) |
| `kanones.js` | Οι τύποι κοπής — η ίδια μηχανή τρέχει και στο κινητό και στον έλεγχο |
| `test.js` | Αυτόματος έλεγχος με τα 3 παραδείγματα του `kanones-kopis.md` |
| `sw.js` | Κρατάει την εφαρμογή στο κινητό για να δουλεύει χωρίς ίντερνετ |
| `manifest.webmanifest`, `eikonidio*.png`, `eikonidio.svg` | Εικονίδιο και όνομα στην αρχική οθόνη |

## Έλεγχος

Χρειάζεται Node.js:

```
node test.js
```

Ελέγχει ότι τα 3 παραδείγματα του αρχείου κανόνων βγαίνουν **ακριβώς** ίδια, ότι ενώνονται τα ίδια κομμάτια, ότι η ντουλάπα χωρίζεται σωστά σε τμήματα, και ότι η ίδια δουλειά δίνει πάντα την ίδια λίστα.

## Σημείωση για το μπάνιο

Στο `kanones-kopis.md` το μπάνιο είναι σημειωμένο ως «να επιβεβαιωθεί». Η εφαρμογή ακολουθεί τους κανόνες του πάνω ντουλαπιού με κόντρα πλακέ θαλάσσης 1,8 για το κουτί και 0,8 για την πλάτη (ακρυλικό στις πόρτες, όπως στην κουζίνα). Αν ο πατέρας πει κάτι άλλο, αλλάζει από τις **Ρυθμίσεις**.
